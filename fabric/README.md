# Microsoft Fabric Workspace Items

This directory is connected to the Microsoft Fabric workspace via **Fabric Git Integration** (`Branch: main`, `Git folder: /fabric`).

Lakehouse metadata, Data Pipelines, Dataflows Gen2, PySpark Notebooks, Warehouse DDL schemas, and Power BI reports are synced here automatically from the Fabric portal. Actual data files and Delta tables remain in **OneLake** and are never committed to Git.
